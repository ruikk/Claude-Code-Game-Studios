# 叙事规则 (Narrative Rules)

- 所有新增设定 (Lore) 必须与现有设定交叉比对，确保无矛盾
- 每条设定条目必须标注正典级别 (Canon Level)：已确立 (Established) / 暂定 (Tentative) / 审核中 (Under Review)
- 角色对话必须符合该角色的语音档案 (Voice Profile)
- 世界规则（可能/不可能之事）必须明确记录并保持一致
- 悬疑情节 (Mystery Plot) 必须记录"真实答案"，即使玩家永远不会得知
- 阵营 (Faction) 的动机、关系和权力结构必须在内部逻辑自洽
- 所有叙事文本必须具备本地化就绪状态 (Localization-Ready)：不使用无法翻译的习语 (Idiom)，变量使用命名占位符 (Named Placeholder)
- 单行对话不得超过 120 个字符，以适应对话框 (Dialogue Box) 约束
