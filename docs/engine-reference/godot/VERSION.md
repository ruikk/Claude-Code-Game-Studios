## 知识缺口警告

LLM 的训练数据可能只覆盖到 Godot ~4.3。4.4、4.5 和 4.6 引入了模型并不了解的重大变化。
提出 Godot API 调用建议前，务必查阅本目录。

## 截止时间后的版本时间线

| 版本 | 发布 | 风险等级 | 主要主题 |
|---------|---------|------------|-----------|
| 4.4 | 约 2025 年中 | MEDIUM | Jolt 物理选项、FileAccess 返回类型、着色器纹理类型变更 |
| 4.5 | 约 2025 年末 | HIGH | 无障碍（AccessKit）、可变参数、@abstract、着色器烘焙器、SMAA |
| 4.6 | 2026 年 1 月 | HIGH | Jolt 默认启用、辉光重构、Windows 默认使用 D3D12、IK 恢复 |
